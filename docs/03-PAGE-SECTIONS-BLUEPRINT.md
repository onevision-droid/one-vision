# 03 — Page Sections Blueprint (Field Edition)

**Project:** One Vision — Society for Health & Education Manipur  
**Scope:** Architectural blueprint for the six primary pages + shared structural sections.  
**Guiding Principle:** Editorial storytelling flow, anti-card soup, purposeful containment, and mobile-first responsiveness.

---

## 1. `/` — Home Page Blueprint

The Home page moves away from a disjointed stack of boxed cards into a cohesive, publication-style civic journal:

```
┌─────────────────────────────────────────────────────────────┐
│ 01. Editorial Hero (Locked Layout - min-h-dvh)              │
│     Statement: Shared Vision. / Local Action.               │
│     Left: Headline + Concise copy + CTAs (Our Work / Join)  │
│     Right: 1:1 Aspect documentary photograph               │
├─────────────────────────────────────────────────────────────┤
│ 02. Proof of Impact (Compact Horizontal Strip)              │
│     2,500+ Families Reached · 500+ Youth Trained ·          │
│     25+ Communities Engaged · 22+ Local Partners            │
│     (Clean horizontal flow, no large card walls)            │
├─────────────────────────────────────────────────────────────┤
│ 03. Five Priorities (Editorial Programme Index)             │
│     Pillar 01: Featured layout (Image + Summary + Metric)   │
│     Pillars 02–05: Clean numbered editorial rows            │
│     Each row: Number, Title, 1-line mission, Metric, Link   │
├─────────────────────────────────────────────────────────────┤
│ 04. One Human Story (Asymmetric Editorial Feature)          │
│     50/50 Split: Dominant documentary portrait +            │
│     Headline, narrative excerpt, consent badge, Read Story  │
├─────────────────────────────────────────────────────────────┤
│ 05. Accountability & Governance (Clean 3-Link Row)          │
│     Open Ledger · Board & Governance · Annual Reports       │
│     Quiet inline navigation, no heavy card grid             │
├─────────────────────────────────────────────────────────────┤
│ 06. Closing Action (Quiet Close)                            │
│     One calm sentence + Primary CTA (Volunteer / Contact)   │
└─────────────────────────────────────────────────────────────┘
```
