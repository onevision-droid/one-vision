# One Vision — Project Blueprint (2026-2030 Pivot)

## Executive Summary
Following the September 2026 strategic review, One Vision, Manipur has abandoned its legacy NGO model in favor of a decentralized, crisis-resilient humanitarian vanguard model.

The legacy operations (traditional hospitals, centralized vocational training) are completely deprecated. 

## The 4 Operational Pillars
1. **Conflict-Resilient Health Equity:** Mobile Tele-Health, Psychiatry, Decentralized ART, Harm reduction.
2. **Energy Sovereignty:** Solar-Kiran renewable microgrids for conflict-affected communities and decentralised health centers.
3. **Ecological Restoration & Agrarian Resilience:** Loktak Lake bio-economy, Indigenous Seed Banks, Regenerative Agroforestry.
4. **Economic Dignity & Livelihood Rehabilitation:** Circular micro-economies, Self-Help Cooperatives for conflict-affected communities.

## Master Documents

The project rules and logic have been decentralized into the following master documents in the repository root:

- **`AGENTS.md`**: Contains the core project identity, design direction (Frontline Humanitarian), technical baseline, accessibility, and strict OpSec rules. This dictates all agent behavior in the repository.
- **`PRODUCT.md`**: Defines the platform's purpose as a secure public beacon and data dashboard, not a marketing site.
- **`CONTENT.md`**: Outlines the urgent, factual editorial voice, the crisis reporting structure, and the absolute necessity of anonymization and OpSec in content publishing.

## Key Directives

1. **Frontline Humanitarian Aesthetic:** The design must be stark, high-contrast, data-heavy, and utilitarian.
2. **Zero In-App Intake:** There are NO sensitive "Get Help" forms on the web platform. All sensitive requests are routed to secure external channels (Signal, ProtonMail).
3. **Decentralized Data:** The platform serves as a transparency beacon, broadcasting unadorned metrics and verifiable data from the 4 pillars.
4. **Resilience:** The application must be built for low-bandwidth, offline-capable operability in a conflict zone with frequent internet blockades.
